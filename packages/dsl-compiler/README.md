# DSL Compiler Package

## Overview

Workspace package root for `@vn-engine/dsl-compiler`, encapsulating Chevrotain and jsep dependencies for offline and worker-based compilation.

## Subdirectories & Boundaries

- src: [./src/README.md](./src/README.md) - Lexer, Parser, AST Builder, Merge Pass, Semantic Validator, Codegen, Formatter, and Compiler entrypoints.
