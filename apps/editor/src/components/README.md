# components

## Overview

UI component layer of the visual novel web editor application. Organized into modular subpackages for character management, common monochrome iconography, project hub management, and the studio authoring environment.

## Subdirectories & Boundaries

- characters: [./characters/README.md](./characters/README.md) - Character roster view, character editing modal, and expression management components.
- common: [./common/README.md](./common/README.md) - Clean monochrome SVG icon component library conforming to the design guidelines.
- hub: [./hub/README.md](./hub/README.md) - Project management dashboard, project cards, and creation/deletion modals.
- studio: [./studio/README.md](./studio/README.md) - Director workspace components including Monaco editor container, file explorer, activity bar, diagnostics dock, preview dock, and settings modals.
