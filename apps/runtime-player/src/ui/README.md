# Player UI Layer

## Overview

Groups all Preact-based visual presentation components, modal windows, layout containers, and reactive context state providers for the Visual Novel Runtime Player.

## Subdirectories & Boundaries

- components: [./components/README.md](./components/README.md) - Presentation components, gameplay overlays, control bar, and modal dialogs.
- context: [./context/README.md](./context/README.md) - PlayerUIContext provider and custom hooks linking VNRuntimeKernel with Preact UI.
