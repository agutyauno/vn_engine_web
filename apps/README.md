# apps

## Overview

Application layer of TaleForge, housing the web-based visual novel authoring studio and the independent runtime player applications.

## Subdirectories & Boundaries

- editor: [./editor/README.md](./editor/README.md) - TaleForge Studio web editor application with Monaco VNS scripting, asset management, and live preview bridge.
- runtime-player: [./runtime-player/README.md](./runtime-player/README.md) - Standalone runtime game player executing compiled bytecode scenarios with PixiJS 2D rendering and Howler audio.
